# DeckDrop

A Decky Loader plugin for receiving files from your Windows PC over your local network. It works with the DeckDrop
app for Windows.

Every transfer needs your approval on the Deck. Accepted files are saved to `~/Documents/DeckDrop`. You can pick a
different folder in the plugin's settings, for example one on the SD card.

## Install

You need [Decky Loader](https://decky.xyz). In Desktop Mode, open Konsole and run:

```sh
curl -fsSL https://raw.githubusercontent.com/JayPrates/deckdrop-decky/main/install.sh | bash
```

Run the same command again to update.
